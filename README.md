# Reporting Analytics & Business Intelligence Operations Internship

## Project Overview
This project demonstrates an end-to-end Reporting Analytics workflow using Python, PostgreSQL, SQL and Tableau. The objective was to clean operational business data, build a relational database, create analytical SQL views, and design an executive dashboard for business decision-making.

## Tech Stack
- Python (Pandas)
- PostgreSQL
- SQL
- Tableau Desktop
- Git & GitHub

## Milestones

### Milestone 1 – Data Profiling
- Profiled 19 business datasets
- Generated profiling report
- Identified missing values and data quality issues

### Milestone 2 – Data Cleaning
- Removed duplicates
- Standardized formats
- Created cleaning log
- Generated data dictionary

### Milestone 3 – PostgreSQL Database
- Imported 19 cleaned datasets
- Created relational database
- Built SQL views
- Added indexes
- Verified 40,912 transaction records

### Milestone 4 – Executive Dashboard
Interactive Tableau dashboard including:
- KPI Cards
- Transactions by Department
- Revenue by Customer Segment
- Fraud Risk by Gateway
- Data Quality by KPI
- Interactive Filters
