# Executive Reporting Analytics Dashboard

## Project Overview
A Reporting & Business Intelligence project that demonstrates data cleaning, SQL data warehousing, PostgreSQL integration, and Tableau dashboard development.

## Tools Used
- Python (Pandas)
- PostgreSQL
- SQL
- Tableau
- Git & GitHub

## Milestones

### Milestone 1
- Data profiling
- Cleaning log
- Data dictionary

### Milestone 2
- Cleaned 19 business datasets
- Generated profiling reports

### Milestone 3
- PostgreSQL database
- 19 SQL tables
- 3 analytical views
- Database verification

### Milestone 4
Interactive Tableau dashboard including:
- Executive KPI cards
- Transactions by Department
- Revenue by Customer Segment
- Fraud Risk by Gateway
- Data Quality by KPI
- Interactive filters
